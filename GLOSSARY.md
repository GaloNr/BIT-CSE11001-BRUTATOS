# Glossary

One definition per term, used the same way in every lesson, the study guide, the slides and the videos. The number in brackets is the section where the term is introduced.

Maintained by: Mussaldinov Rassul (Research & Learning Lead). Last updated: 5 November 2026.

| Term | Meaning |
| --- | --- |
| Accumulator (ACC) | Register that holds the result of the latest calculation (1.4) |
| Acknowledgement (ACK) | Short reply meaning "I received this" (2.5) |
| Action | What an agent does at one moment (3.3) |
| Actuator | Part that makes something happen in the world, usually a motor; an output device (1.7) |
| Address (memory) | The number of a place in memory; different from the value stored there (1.3) |
| Agent | Anything that perceives its environment through sensors and acts on it through actuators (3.3) |
| ALU | Arithmetic logic unit: part of the CPU that does maths and comparisons (1.3) |
| ASCII | Code that gives each English letter, digit and symbol a number, e.g. A = 65 (1.2) |
| Behavior | A small, complete sense-act unit with one job (3.4) |
| Behaviorism (AI) | School of AI that sees intelligence in acting well in the real world through direct sense-act links (3.1) |
| Binary | Writing numbers with only 0 and 1 (1.2) |
| Bit | One binary digit, 0 or 1 (1.2) |
| Bus | Set of wires carrying addresses, data or control signals between CPU and memory (1.3) |
| Byte | 8 bits; stores 256 values, 0 to 255 (1.2) |
| Cache | Small, very fast memory on the CPU chip holding recently used data (1.5) |
| Circuit switching | Reserving one fixed path for a whole conversation (2.2) |
| Clock speed | Ticks per second of the CPU clock, in GHz (1.6) |
| Condition-action rule | IF-THEN rule linking a percept to an action (3.3) |
| Connectionism | School of AI that learns patterns from examples with neural networks (3.1) |
| Control unit | Part of the CPU that reads instructions and gives orders (1.3) |
| Core | One complete processing unit inside a CPU (1.6) |
| CPU | Central processing unit: carries out instructions (1.3) |
| Cybernetics | Study of control and communication in machines and living things (3.2) |
| DNS | Domain Name System: translates domain names into IP addresses (2.6) |
| Domain name | Human-friendly name of a computer on the internet, e.g. www.bit.edu.cn (2.6) |
| Dusty | The robot vacuum used as the running example in every lesson (1.1) |
| Emergent behavior | Behavior of a whole system that comes from simple rules interacting with the environment (3.6) |
| Encapsulation | Each network layer wrapping the data in its own header (2.4) |
| Environment | The part of the world an agent lives in and acts on (3.3) |
| Feedback loop | Repeating cycle: measure, compare with the goal, act, measure again (3.2) |
| Fetch, decode, execute cycle | How a CPU runs every instruction, one at a time (1.4) |
| GPU | Graphics processing unit: thousands of small cores working in parallel (1.7) |
| Hardware | The physical parts of a computer (1.1) |
| Header | Label at the front of a packet: addresses, sequence number (2.2) |
| HTTP / HTTPS | Protocol for requesting web pages; HTTPS adds encryption (2.7) |
| Hybrid system | System combining approaches, e.g. reactive safety plus map and planning (3.6) |
| Input / Processing / Storage / Output | The four jobs of every computer (1.1) |
| IP address | Number that identifies a device on a network; IPv4 = 4 bytes (2.3) |
| LAN / WAN | Local area network (one place, one owner) / wide area network (many networks joined) (2.1) |
| MAC address | Hardware address of a network card, used inside one LAN (2.3) |
| Memory (RAM) | Main memory holding programs and data in use; volatile (1.3, 1.5) |
| Negative feedback | Feedback that reduces the difference from the goal and keeps things stable (3.2) |
| Packet | Small piece of data sent across a network, with a header (2.2) |
| Percept | What an agent's sensors report at one moment (3.3) |
| Phishing | Tricking people into giving passwords or money with fake sites or messages (2.7) |
| Policy | An agent's strategy: which action to choose in each state (3.5) |
| Port | Number that tells which program on a device should receive data (2.3) |
| Program counter (PC) | Register holding the address of the next instruction (1.4) |
| Protocol | Agreed rules for communication (2.4) |
| Reactive agent | Agent that decides only from the current percept, with no memory or plan (3.3) |
| Register | Tiny, very fast storage inside the CPU (1.3) |
| Reinforcement learning | Learning which actions are good from rewards and penalties (3.5) |
| Reward | Number an agent receives after an action: positive good, negative bad (3.5) |
| Router | Device that connects networks and forwards data between them (2.1) |
| Sensor | Part that measures something in the world; an input device (1.7) |
| Software | Instructions that tell hardware what to do (1.1) |
| State | The situation an agent is in (3.5) |
| Stored-program idea | Programs are kept in memory, in the same memory as data (1.3) |
| Subsumption architecture | Brooks's design: layers of simple behaviors, higher layers can suppress lower ones (3.4) |
| Switch | Device that connects devices inside one LAN (2.1) |
| TCP | Transport protocol that delivers all data, in order (2.5) |
| TCP/IP model | Four-layer model of the internet: application, transport, internet, link (2.4) |
| UDP | Transport protocol that sends without checking or resending; fast (2.5) |
| Volatile / non-volatile | Loses / keeps its contents without power (1.5) |
